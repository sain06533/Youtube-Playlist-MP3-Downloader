# Youtube-Playlist-MP3-Downloader
A python script that will download songs from youtube playlists

YouTube Music Downloader (GUI) -> 320 kbps MP3 with cover art + tags.

Setup:

    pip install -U yt-dlp
    Install ffmpeg (winget install ffmpeg / brew install ffmpeg / apt install ffmpeg)
    Linux only: sudo apt install python3-tk

Run:

    python ytm.py


For easier use, you it in a browser with a single profile.

Note: You will need to be signed in for this tool to work.




Use this tool at your own discretion.
